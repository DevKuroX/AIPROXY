## Objective

Add an ESLint rule (or CI grep step) that fails the build if any NEW file imports from forbidden SQLite paths. Whitelist current importers.


### Step 2: Create ESLint Rule

Option A — Custom ESLint rule:

```javascript
// eslint-rules/no-sqlite-imports.js

module.exports = {
  meta: {
    type: 'problem',
    docs: { description: 'Block new SQLite imports' },
    schema: [{ type: 'array', items: { type: 'string' } }],
  },
  create(context) {
    const blocked = [
      '@/lib/db/',
      '@/lib/usageDb',
      '@/lib/localDb',
      '@/lib/disabledModelsDb',
      '@/lib/requestDetailsDb',
      '@/lib/dataDir',
    ];
    
    const whitelist = context.options[0] || [];
    
    return {
      ImportDeclaration(node) {
        const source = node.source.value;
        
        if (blocked.some(b => source.includes(b))) {
          const filePath = context.getFilename();
          
          if (!whitelist.some(w => filePath.includes(w))) {
            context.report({
              node,
              message: `New SQLite imports are forbidden. Use src/lib/*-api.ts instead.`,
            });
          }
        }
      },
    };
  },
};
```

Option B — Simple grep in CI:

```bash
# .github/workflows/ci.yml

- name: Block new SQLite imports
  run: |
    cd frontend
    
    # Whitelist current importers
    WHITELIST="current-importer-1.ts|current-importer-2.ts"
    
    # Check for new imports
    VIOLATIONS=$(rg -l "from ['\"]@/lib/(db/|usageDb|localDb|disabledModelsDb|requestDetailsDb|dataDir)" src/ | grep -vE "$WHITELIST" || true)
    
    if [ -n "$VIOLATIONS" ]; then
      echo "ERROR: New SQLite imports found:"
      echo "$VIOLATIONS"
      exit 1
    fi
```

### Step 3: Configure ESLint

```javascript
// eslint.config.mjs

import noSQLiteImports from './eslint-rules/no-sqlite-imports.js';

export default [
  {
    plugins: { 'migration': { rules: { 'no-sqlite-imports' } } },
    rules: {
      'migration/no-sqlite-imports': ['error', [
        // Whitelist from T0.1
        'src/app/api/legacy-route.ts',
        'src/components/old-component.tsx',
      ]],
    },
  },
];
```
