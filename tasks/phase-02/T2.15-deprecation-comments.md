## Objective

Add deprecation comments to shim files (`usageDb.js`, `localDb.js`, `db/`) warning that they will be removed in Phase 8.

## Source Documents

- `FRONTEND_MIGRATION_TASK_INDEX.md` § Phase 2
- `PROJECT_CONSTRAINTS.md`

## Prerequisites

- T2.14 complete (ESLint SQLite blocking)

## Execution

### Step 1: Add Deprecation Header to usageDb.js

```javascript
/**
 * @deprecated
 * This module will be REMOVED in Phase 8.
 * 
 * All imports should migrate to:
 * - src/lib/usage-api.ts for usage data
 * 
 * DO NOT add new consumers of this module.
 * See FRONTEND_MIGRATION_TASK_INDEX.md for migration guide.
 */
```

### Step 2: Add Deprecation Header to localDb.js

```javascript
/**
 * @deprecated
 * This module will be REMOVED in Phase 8.
 * 
 * All imports should migrate to:
 * - src/lib/settings-api.ts for settings
 * - src/lib/providers-api.ts for providers
 * - src/lib/combos-api.ts for combos
 * - src/lib/keys-api.ts for keys
 * - etc. (see T2.1 catalog for full list)
 * 
 * DO NOT add new consumers of this module.
 * See FRONTEND_MIGRATION_TASK_INDEX.md for migration guide.
 */
```

### Step 3: Add Deprecation Header to db/index.js

```javascript
/**
 * @deprecated
 * This module will be REMOVED in Phase 8.
 * 
 * SQLite is NO LONGER SUPPORTED in frontend.
 * All data must come from backend API.
 * 
 * DO NOT add new consumers of this module.
 * See FRONTEND_MIGRATION_TASK_INDEX.md for migration guide.
 */
```

### Step 4: Add Deprecation to Other Shim Files

Apply same pattern to:
- `src/lib/disabledModelsDb.js`
- `src/lib/requestDetailsDb.js`
- `src/lib/mitmAliasCache.js`
- `src/lib/dataDir.js`
