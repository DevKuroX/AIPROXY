## Execution

### Step 1: Update ESLint Config

Add to `eslint.config.mjs` or `eslintrc.js`:

```javascript
{
  rules: {
    'no-restricted-imports': ['error', {
      patterns: [{
        group: ['**/open-sse/**'],
        message: 'open-sse is deprecated. Use @/sse/consumer instead.'
      }, {
        group: ['@/open-sse'],
        message: 'open-sse is deleted. Use @/sse/consumer for streaming.'
      }]
    }]
  }
}
```

### Step 2: Verify Lint Works

```bash
cd /home/ubuntu/ai_proxy/frontend
npm run lint
```

Should pass (no open-sse imports exist).

Run lint:

```bash
npm run lint
```

Should fail with error.

Remove test import.
