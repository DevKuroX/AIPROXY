## Objective

## Execution

### Step 1: Add Environment Variable

Add to `.env.local` and `.env.example`:

```bash
# Stream V2 - new normalized consumer
NEXT_PUBLIC_STREAM_V2=false
```

### Step 2: Create Feature Flag Check

```typescript
// src/lib/features.ts
export function isStreamV2Enabled(): boolean {
  return process.env.NEXT_PUBLIC_STREAM_V2 === 'true';
}
```

### Step 3: Gate Consumer Usage

```typescript
// In chat component
import { isStreamV2Enabled } from '@/lib/features';
import { consumePostStream } from '@/sse/consumer';
import { legacyStreamHandler } from '@/open-sse/consumer';

const handleStream = async (response: Response) => {
  if (isStreamV2Enabled()) {
    await consumePostStream(response, callbacks);
  } else {
    await legacyStreamHandler(response, callbacks);
  }
};
```

### Step 4: Test Both Paths

1. With flag OFF: test legacy path
2. With flag ON: test new consumer

```bash
# Test legacy
NEXT_PUBLIC_STREAM_V2=false npm run dev

# Test new
NEXT_PUBLIC_STREAM_V2=true npm run dev
```

### Step 5: Verify Build

```bash
tsc --noEmit
npm run build
```
