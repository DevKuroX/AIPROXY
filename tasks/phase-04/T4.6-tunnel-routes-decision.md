## Execution

### Step 1: Identify Tunnel Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/tunnel -name "route.*" -type f
```

### Step 2: Read Current Implementation

```bash
cat src/app/api/tunnel/route.ts
```

### Step 3: Check Appendix-A Decision

From T0.9 PM decisions, check:
- Is MITM/tunnel in scope for AIPROXY?
- Is backend tunnel equivalent available?

### Step 4: Determine Action

Decision tree:

| Condition | Action |
|-----------|--------|
| Tunnel in scope, backend has endpoint | PROXY |
| Tunnel NOT in scope | DELETE |
| Partial tunnel functionality | Evaluate per-endpoint |

### Step 5: Check Backend

```bash
cd /home/ubuntu/ai_proxy/backend
rg -n "tunnel" internal/api/
```

### Step 6: Execute Decision

#### If DELETE:

1. Find all consumers:
```bash
rg -n "api/tunnel" src/
rg -n "@/lib/tunnel" src/
```

2. Remove or update consumers

3. Delete route files:
```bash
rm -rf src/app/api/tunnel/
```

#### If PROXY:

1. Apply standard `proxyToBackend` pattern

2. Verify functionality

### Step 7: Verify Build

```bash
tsc --noEmit
npm run build
```
