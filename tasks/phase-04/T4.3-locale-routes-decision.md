## Execution

### Step 1: Identify Locale Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/locale -name "route.*" -type f
```

### Step 2: Read Current Implementation

```bash
cat src/app/api/locale/route.ts
```

### Step 3: Determine Action

Decision tree:

| Condition | Action |
|-----------|--------|
| Backend has equivalent endpoint | PROXY |
| Pure frontend i18n functionality | KEEP-AS-IS |
| Mix of frontend/backend logic | Evaluate per-function |

### Step 4: Check Backend

```bash
cd /home/ubuntu/ai_proxy/backend
rg -n "locale|i18n" internal/api/
```

### Step 5: Execute Decision

#### If KEEP-AS-IS:

Locale routes are typically frontend-only for i18n management.

1. Verify no SQLite usage:
```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/locale/
```

2. If SQLite present, evaluate migration

3. Document decision

#### If PROXY:

1. Apply standard `proxyToBackend` pattern

2. Verify functionality

### Step 6: Verify Build

```bash
tsc --noEmit
npm run build
```
