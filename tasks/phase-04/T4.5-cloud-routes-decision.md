## Objective

Decide and execute action for `api/cloud/*` routes. Depends on Appendix-A; if cloud mode not in scope → DELETE.

## Source Documents

- `FRONTEND_MIGRATION_TASK_INDEX.md` § Phase 4
- `BUILD_RULES.md`
- T0.9 PM decisions (Appendix-A)

## Prerequisites

- T4.4 complete
- T0.9 PM decisions available

## Execution

### Step 1: Identify Cloud Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/cloud -name "route.*" -type f
```

### Step 2: Read Current Implementation

```bash
cat src/app/api/cloud/route.ts
```

### Step 3: Check Appendix-A Decision

From T0.9 PM decisions, check:
- Is cloud sync in scope for AIPROXY?
- Is backend cloud equivalent available?

### Step 4: Determine Action

Decision tree:

| Condition | Action |
|-----------|--------|
| Cloud mode in scope, backend has endpoint | PROXY |
| Cloud mode NOT in scope | DELETE |
| Partial cloud functionality | Evaluate per-endpoint |

### Step 5: Check Backend

```bash
cd /home/ubuntu/ai_proxy/backend
rg -n "cloud" internal/api/
```

### Step 6: Execute Decision

#### If DELETE:

1. Find all consumers:
```bash
rg -n "api/cloud" src/
rg -n "initCloudSync" src/
```

2. Remove or update consumers

3. Delete route files:
```bash
rm -rf src/app/api/cloud/
```

#### If PROXY:

1. Apply standard `proxyToBackend` pattern

2. Verify functionality

### Step 7: Verify Build

```bash
tsc --noEmit
npm run build
```
