## Execution

### Step 1: Identify CLI Tools Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/cli-tools -name "route.*" -type f
```

### Step 2: Read Current Implementation

```bash
cat src/app/api/cli-tools/route.ts
```

### Step 3: Check Appendix-A Decision

From T0.9 PM decisions, check:
- Is CLI tools in scope?
- Is backend equivalent available?

### Step 4: Determine Action

Decision tree:

| Condition | Action |
|-----------|--------|
| Backend has equivalent endpoint | PROXY |
| CLI tools out of scope | DELETE |
| Mix of functionality | Evaluate per-endpoint |

### Step 5: Check Backend

```bash
cd /home/ubuntu/ai_proxy/backend
rg -n "cli" internal/api/
```

### Step 6: Execute Decision

#### If DELETE:

1. Find all consumers:
```bash
rg -n "api/cli-tools" src/
```

2. Remove or update consumers

3. Delete route files:
```bash
rm -rf src/app/api/cli-tools/
```

#### If PROXY:

1. Apply standard `proxyToBackend` pattern

2. Verify functionality

### Step 7: Verify Build

```bash
tsc --noEmit
npm run build
```
