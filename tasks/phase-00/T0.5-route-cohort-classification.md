## Execution

### Step 1: Inventory All Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api -name "route.ts" -o -name "route.js" | sort
```

### Step 2: Read Each Route File

For each route file:
1. Read the file content
2. Check for imports: `usageDb`, `localDb`, `db/`, business logic modules
3. Check for direct `fetch()` to backend
4. Classify based on findings

### Step 3: Produce Classification Report

Create:
```
docs/migration/inventory/route-cohorts.md
```

## Classification Criteria

| Classification | Criteria |
|----------------|----------|
| **Cohort A** | Contains only `fetch(BACKEND_URL)` or equivalent; no local DB imports; no business logic |
| **Cohort B** | Contains business logic, SQLite imports, provider execution, or complex transformations |
| **Uncertain** | Requires backend/human review |
