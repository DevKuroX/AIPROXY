## Objective

Capture HAR (HTTP Archive) fixtures for the top 10 user flows. These serve as baseline for regression testing during migration.

## Source Documents

## Top 10 User Flows

1. **Login** — Email/password authentication
2. **Dashboard Load** — Initial page render with data
3. **Providers CRUD** — List, create, update, delete providers
4. **Keys CRUD** — List, create, update, delete API keys
5. **Settings Save** — Update user settings
6. **Usage Chart** — View usage statistics
7. **Chat Stream** — Initiate streaming chat request
8. **OAuth Start** — Begin OAuth flow
9. **OAuth Callback** — Complete OAuth flow
10. **Logout** — End session

## Execution

### Step 1: Set Up HAR Capture

Option A — Browser DevTools:
1. Open Chrome DevTools
2. Go to Network tab
3. Check "Preserve log"
4. Export as HAR

Option B — mitmproxy:
```bash
mitmproxy --save-stream-file flow.har
```

Option C — Playwright:
```typescript
import { chromium } from 'playwright';

const browser = await chromium.launch();
const context = await browser.newContext();
const page = await context.newPage();

// Capture HAR
await page.route('**', route => route.continue());

// Perform flow...

await page.context().storageState({ path: 'state.json' });
```

### Step 2: Execute Each Flow

For each flow:
1. Start fresh session
2. Enable HAR capture
3. Execute flow manually or via script
4. Save HAR with descriptive name
