## Execution

### Step 1: Run depcheck

```bash
cd /home/ubuntu/ai_proxy/frontend
npx depcheck
```

### Step 2: Analyze Output

`depcheck` will report:
- **Unused dependencies** — packages imported nowhere
- **Missing dependencies** — packages used but not in package.json
- **Unused devDependencies** — dev-only packages unused

### Step 3: Triage Each Unused Package

For each package flagged as unused:

1. **Search for usage**
   ```bash
   rg -n "package-name" src/
   ```

2. **Check if runtime-loaded**
   - Some packages are loaded dynamically
   - Check webpack config, next.config.js

3. **Decision**
   - Confirmed unused → Remove
   - Used but not detected → Document exception
   - Uncertain → Keep with comment

### Step 4: Remove Unused Packages

```bash
npm uninstall <package-name>
```

### Step 5: Verify Build

```bash
npm run build
```

### Step 6: Commit

```bash
git add package.json package-lock.json
git commit -m "chore: remove unused dependencies (T10.1)"
```
