## Prerequisites

- T10.1 complete (dependency cleanup)

## Execution

### Step 1: Install depcheck if Needed

```bash
cd /home/ubuntu/ai_proxy/frontend
npm install -g depcheck  # or npx depcheck
```

### Step 2: Run depcheck

```bash
depcheck
```

Or:

```bash
npx depcheck
```

### Step 3: Analyze Output

depcheck will output:
- Unused dependencies
- Missing dependencies
- Unused devDependencies

Example output:
```
Unused dependencies
* better-sqlite3
* sqlite3
* unused-package

Unused devDependencies
* test-helper-unused
```

### Step 4: Evaluate Each Unused Dependency

| Dependency | Reason | Action |
|------------|--------|--------|
| better-sqlite3 | Removed in Phase 8 | Already removed |
| unused-package | Not used | REMOVE |
| test-helper | Dev tool, may be needed | EVALUATE |

### Step 5: Remove Unused Dependencies

```bash
npm uninstall unused-package-1 unused-package-2
```

### Step 6: Verify Build

```bash
tsc --noEmit
npm run build
```
