## Execution

### Step 1: Find Ad-Hoc Test Files

```bash
cd /home/ubuntu/ai_proxy/frontend
ls -la test-*.js
ls -la serve-static.js
ls -la login-test.js
ls -la *.js | grep -v node_modules
```

### Step 2: Evaluate Each File

| File | Purpose | Action |
|------|---------|--------|
| test-api.js | API testing | Move to `tests/manual/` |
| serve-static.js | Development tool | Move to `scripts/` or DELETE |
| login-test.js | Login testing | Move to `tests/manual/` or DELETE |

### Step 3: Create Proper Directories

```bash
mkdir -p tests/manual
mkdir -p scripts
```

### Step 4: Move or Delete

```bash
# Move useful scripts
mv test-api.js tests/manual/

# Delete obsolete scripts
rm -f obsolete-test.js
```

### Step 5: Verify Build

```bash
tsc --noEmit
npm run build
```
