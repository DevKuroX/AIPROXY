## Execution

### Step 1: Find Unused Files

```bash
cd /home/ubuntu/ai_proxy/frontend
# Find files not imported anywhere
find src -name "*.ts" -o -name "*.tsx" | while read f; do
  name=$(basename "$f")
  if ! rg -n "$name" src/ --include="*.ts" --include="*.tsx" | grep -v "$f" > /dev/null; then
    echo "UNUSED: $f"
  fi
done
```

### Step 2: Identify Files to Remove

| File | Reason | Action |
|------|--------|--------|
| src/lib/old-util.ts | Not imported | REMOVE |
| src/components/Old.tsx | Replaced | REMOVE |
| src/types/deprecated.ts | Not used | REMOVE |

### Step 3: Remove Files

```bash
rm -f src/lib/old-util.ts
rm -f src/components/Old.tsx
```

### Step 4: Verify Build

```bash
tsc --noEmit
npm run build
```
