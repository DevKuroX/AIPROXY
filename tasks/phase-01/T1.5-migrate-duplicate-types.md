## Objective

Migrate existing duplicate types in `src/lib/admin-api.ts`, `analytics-api.ts`, `oauth-api.ts` to import from `src/shared/contracts/`.

## Source Documents

- `FRONTEND_MIGRATION_TASK_INDEX.md` § Phase 1
- T1.4 created contracts

## Prerequisites

- T1.4 complete (contracts exist)

## Execution

### Step 1: Identify Duplicate Types

```bash
cd /home/ubuntu/ai_proxy/frontend

# Find type definitions in API files
rg -n "^(interface|type) " src/lib/admin-api.ts src/lib/analytics-api.ts src/lib/oauth-api.ts
```

### Step 2: Compare with Contracts

For each type in API files:
1. Check if equivalent exists in `src/shared/contracts/`
2. If yes → replace import
3. If no → evaluate: add to contracts or keep local?

### Step 3: Update Imports

```typescript
// Before (admin-api.ts)
interface LoginResponse { token: string; user: { id: string; email: string } }

// After
import { LoginResponse } from '@/shared/contracts';
```

### Step 4: Remove Local Definitions

Delete the duplicate interface/type definitions after migration.

### Step 5: Verify

```bash
tsc --noEmit
next build
```
