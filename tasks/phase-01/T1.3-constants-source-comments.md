## Objective

For each constant that mirrors a backend value (provider list, error codes, model alias keys), add header comment: `// SOURCE: backend (do not edit locally)`.

## Source Documents

- `FRONTEND_MIGRATION_TASK_INDEX.md` § Phase 1

## Prerequisites

- T1.2 complete (constants index normalized)

## Execution

### Step 1: Identify Backend-Mirrored Constants

```bash
cd /home/ubuntu/ai_proxy/frontend

# List all constant files
ls -la src/shared/constants/
```

Review each file for constants that mirror backend values:
- Provider lists
- Error codes
- Model alias keys
- API endpoint patterns
- Default configurations that backend also defines

### Step 2: Add Source Comments

For each identified constant, add header comment:

```typescript
// SOURCE: backend (do not edit locally)
export const PROVIDER_LIST = [...];

// SOURCE: backend (do not edit locally)
export const ERROR_CODES = {...};
```

### Step 3: Document Non-Backend Constants

For constants that are frontend-only, add clarifying comment:

```typescript
// Frontend-only: used for UI state management
export const UI_CONSTANTS = {...};
```

### Step 4: Verify

```bash
tsc --noEmit
```
