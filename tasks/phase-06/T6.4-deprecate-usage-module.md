# T6.4 — Deprecate usage Module

## Task Identity

| Field | Value |
|-------|-------|
| **Task ID** | T6.4 |
| **Phase** | Phase 6 — Legacy Module Deprecation |
| **Type** | delete |
| **Risk** | 🟠 High |

## Objective

Replace all consumers of `src/lib/usage/` with `usage-api.ts` from T2.5, then delete the directory.

## Source Documents

- `FRONTEND_MIGRATION_TASK_INDEX.md` § Phase 6
- T0.2 legacy import inventory
- T2.5 usage-api.ts

## Prerequisites

- T2.5 complete (usage-api.ts exists)
- T0.2 inventory available

## Execution

### Step 1: List Consumers

From T0.2 inventory:
```bash
cat docs/migration/inventory/legacy-importers.txt | grep "usage/"
```

### Step 2: Replace Each Consumer

For each file importing from `@/lib/usage`:

1. **Read the file**
   ```bash
   cat src/components/UsageChart.tsx
   ```

2. **Identify imports and usage**
   ```typescript
   // Before
   import { getUsageStats } from '@/lib/usage';
   ```

3. **Replace with API client**
   ```typescript
   // After
   import { getUsageStats } from '@/lib/usage-api';
   ```

4. **Verify types match**
   - Function signatures should be identical
   - Response shapes should be identical

5. **Run type check**
   ```bash
   tsc --noEmit
   ```

6. **Test the feature**
   - Usage charts display correctly
   - Data matches expected values

### Step 3: Verify Zero Imports

```bash
rg -n "from ['\"]@/lib/usage" src/

# MUST return zero matches
```

### Step 4: Delete Directory

```bash
rm -rf src/lib/usage/
```

### Step 5: Build and Smoke

```bash
npm run build
npm run dev
# Test usage charts
```

### Step 6: Commit

```bash
git add -A
git commit -m "refactor: deprecate usage module (T6.4)

All usage functions now come from backend via usage-api.ts.
"
```
