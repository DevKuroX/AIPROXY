## Execution

### Step 1: List OAuth Module Consumers

```bash
cd /home/ubuntu/ai_proxy/frontend
rg -n "from ['\"]@/lib/oauth" src/
rg -n "from ['\"].*oauth" src/lib/
```

### Step 2: Identify Functions Used

For each consumer, identify:
- Which functions are imported
- What the function does
- If `oauth-api.ts` has equivalent

### Step 3: Replace Each Consumer

```typescript
// Before
import { getOAuthProviders, startOAuth } from '@/lib/oauth';

// After
import { getOAuthProviders, startOAuth } from '@/lib/oauth-api';
```

Ensure `oauth-api.ts` has all needed functions.

### Step 4: Verify Zero Imports

```bash
rg -n "from ['\"]@/lib/oauth" src/
```

Must return zero matches.

### Step 5: Run TypeScript Check

```bash
tsc --noEmit
```

### Step 6: Run Build

```bash
npm run build
```

### Step 7: Smoke Test

- Test OAuth login flow
- Test OAuth provider listing
- Test OAuth callback

### Step 8: Delete OAuth Module

```bash
rm -rf src/lib/oauth/
```

### Step 9: Verify Build

```bash
tsc --noEmit
npm run build
```
