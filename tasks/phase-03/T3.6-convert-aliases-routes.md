# T3.6 — Convert Aliases Routes

## Task Identity

| Field | Value |
|-------|-------|
| **Task ID** | T3.6 |
| **Phase** | Phase 3 — Cohort A Route Proxy |
| **Type** | migration |
| **Risk** | 🟠 High |

## Objective

Convert `src/app/api/aliases/*` routes to use `proxyToBackend`. Remove all SQLite usage.

## Source Documents

- `FRONTEND_MIGRATION_TASK_INDEX.md` § Phase 3
- `API_CONTRACT.md` § Aliases
- `BUILD_RULES.md`

## Prerequisites

- T3.0 complete (proxy helper exists)
- T3.1 complete (proxy helper tested)

## Execution

### Step 1: Identify Alias Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/aliases -name "route.*" -type f
```

Expected routes:
- `src/app/api/aliases/route.ts` (GET, POST)
- `src/app/api/aliases/[id]/route.ts` (DELETE)

### Step 2: Capture HAR Before

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/aliases
curl -X POST -H "Authorization: Bearer <token>" -d '{"alias":"gpt4","model":"gpt-4"}' http://localhost:3000/api/aliases
```

### Step 3: Read Current Implementation

```bash
cat src/app/api/aliases/route.ts
cat src/app/api/aliases/[id]/route.ts
```

### Step 4: Identify SQLite Usage

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/aliases/
```

### Step 5: Convert to Proxy Pattern

```typescript
import { proxyToBackend } from '@/lib/proxy';

export async function GET(request: Request) {
  return proxyToBackend(request, '/api/aliases');
}

export async function POST(request: Request) {
  return proxyToBackend(request, '/api/aliases');
}
```

### Step 6: Verify No SQLite Imports

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/aliases/
```

Must return zero matches.

### Step 7: Test Endpoints

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/aliases
```

### Step 8: Verify Build

```bash
tsc --noEmit
npm run build
```
