# T3.7 — Convert Combos Routes

## Task Identity

| Field | Value |
|-------|-------|

## Objective

Convert `src/app/api/combos/*` routes to use `proxyToBackend`. Remove all SQLite usage.

## Execution

### Step 1: Identify Combo Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/combos -name "route.*" -type f
```

Expected routes:
- `src/app/api/combos/route.ts` (GET, POST)
- `src/app/api/combos/[id]/route.ts` (PUT, DELETE)

### Step 2: Capture HAR Before

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/combos
curl -X POST -H "Authorization: Bearer <token>" -d '{"name":"combo1"}' http://localhost:3000/api/combos
```

### Step 3: Read Current Implementation

```bash
cat src/app/api/combos/route.ts
cat src/app/api/combos/[id]/route.ts
```

### Step 4: Identify SQLite Usage

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/combos/
```

### Step 5: Convert to Proxy Pattern

```typescript
import { proxyToBackend } from '@/lib/proxy';

export async function GET(request: Request) {
  return proxyToBackend(request, '/api/combos');
}

export async function POST(request: Request) {
  return proxyToBackend(request, '/api/combos');
}
```

### Step 6: Verify No SQLite Imports

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/combos/
```

Must return zero matches.

### Step 7: Test Endpoints

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/combos
```

### Step 8: Verify Build

```bash
tsc --noEmit
npm run build
```
