## Execution

### Per-Route Checklist

For each route file:

1. **Read existing route file**
   ```bash
   cat src/app/api/auth/login/route.ts
   ```

2. **If already calls `fetch(BACKEND_URL)`**
   - Mark as done
   - Skip

3. **Otherwise, replace with proxy template:**
   ```typescript
   // src/app/api/auth/login/route.ts
   
   import { NextRequest } from 'next/server';
   import { proxyToBackend } from '@/lib/proxy';
   
   export async function POST(req: NextRequest) {
     return proxyToBackend(req);
   }
   ```

4. **Remove forbidden imports:**
   - `usageDb`
   - `localDb`
   - `db/`
   - Any business logic

5. **Capture HAR before/after**
   - Use T0.10 fixtures as baseline
   - Run new HAR for comparison

6. **Diff status/body/headers**
   - Allowlist: `content-type`, `content-length`, `set-cookie`

7. **Commit**

### Example Conversions

#### Auth Login

```typescript
// Before (hypothetical)
import { NextRequest, NextResponse } from 'next/server';
import { validateUser } from '@/lib/auth';

export async function POST(req: NextRequest) {
  const body = await req.json();
  const result = await validateUser(body.email, body.password);
  return NextResponse.json(result);
}

// After
import { NextRequest } from 'next/server';
import { proxyToBackend } from '@/lib/proxy';

export async function POST(req: NextRequest) {
  return proxyToBackend(req);
}
```

#### Health Check

```typescript
// After
import { NextRequest } from 'next/server';
import { proxyToBackend } from '@/lib/proxy';

export async function GET(req: NextRequest) {
  return proxyToBackend(req, '/health');
}
```
