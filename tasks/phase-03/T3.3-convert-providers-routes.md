## Execution

### Step 1: Identify Provider Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/providers -name "route.*" -type f
```

Expected routes:
- `src/app/api/providers/route.ts` (GET, POST)
- `src/app/api/providers/[id]/route.ts` (GET, PUT, DELETE)

### Step 2: Capture HAR Before

```bash
# Start dev server
npm run dev

# Capture baseline requests
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/providers
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/providers/<id>
```

### Step 3: Read Current Implementation

```bash
cat src/app/api/providers/route.ts
cat src/app/api/providers/[id]/route.ts
```

### Step 4: Identify SQLite Usage

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/providers/
```

### Step 5: Convert to Proxy Pattern

For each route:

```typescript
// Before
import { getProviders } from '@/lib/localDb';

export async function GET() {
  const providers = await getProviders();
  return Response.json({ providers });
}

// After
import { proxyToBackend } from '@/lib/proxy';

export async function GET(request: Request) {
  return proxyToBackend(request, '/api/providers');
}

export async function POST(request: Request) {
  return proxyToBackend(request, '/api/providers');
}
```

### Step 6: Verify No SQLite Imports

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/providers/
```

Must return zero matches.

### Step 7: Test Endpoints

```bash
# After conversion
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/providers
curl -X POST -H "Authorization: Bearer <token>" -d '{"name":"test"}' http://localhost:3000/api/providers
```

### Step 8: Verify Build

```bash
tsc --noEmit
npm run build
```
