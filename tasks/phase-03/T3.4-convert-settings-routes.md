Convert `src/app/api/settings/*` routes to use `proxyToBackend`. Remove all SQLite usage.

## Execution

### Step 1: Identify Settings Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/settings -name "route.*" -type f
```

Expected routes:
- `src/app/api/settings/route.ts` (GET, POST)

### Step 2: Capture HAR Before

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/settings
curl -X POST -H "Authorization: Bearer <token>" -d '{"theme":"dark"}' http://localhost:3000/api/settings
```

### Step 3: Read Current Implementation

```bash
cat src/app/api/settings/route.ts
```

### Step 4: Identify SQLite Usage

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/settings/
```

### Step 5: Convert to Proxy Pattern

```typescript
// Before
import { getSettings, saveSettings } from '@/lib/localDb';

export async function GET() {
  const settings = await getSettings();
  return Response.json(settings);
}

// After
import { proxyToBackend } from '@/lib/proxy';

export async function GET(request: Request) {
  return proxyToBackend(request, '/api/settings');
}

export async function POST(request: Request) {
  return proxyToBackend(request, '/api/settings');
}
```

### Step 6: Verify No SQLite Imports

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/settings/
```

Must return zero matches.

### Step 7: Test Endpoints

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/settings
curl -X POST -H "Authorization: Bearer <token>" -d '{"theme":"light"}' http://localhost:3000/api/settings
```

### Step 8: Verify Build

```bash
tsc --noEmit
npm run build
```
