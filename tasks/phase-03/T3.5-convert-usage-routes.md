## Execution

### Step 1: Identify Usage Routes

```bash
cd /home/ubuntu/ai_proxy/frontend
find src/app/api/usage -name "route.*" -type f
```

Expected routes:
- `src/app/api/usage/route.ts` (GET)

### Step 2: Capture HAR Before

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/usage
```

### Step 3: Read Current Implementation

```bash
cat src/app/api/usage/route.ts
```

### Step 4: Identify SQLite Usage

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/usage/
```

### Step 5: Convert to Proxy Pattern

```typescript
// Before
import { getUsage } from '@/lib/usageDb';

export async function GET() {
  const usage = await getUsage();
  return Response.json(usage);
}

// After
import { proxyToBackend } from '@/lib/proxy';

export async function GET(request: Request) {
  return proxyToBackend(request, '/api/usage');
}
```

### Step 6: Verify No SQLite Imports

```bash
rg -n "usageDb|localDb|@/lib/db" src/app/api/usage/
```

Must return zero matches.

### Step 7: Test Endpoints

```bash
curl -H "Authorization: Bearer <token>" http://localhost:3000/api/usage
```

### Step 8: Verify Build

```bash
tsc --noEmit
npm run build
```
