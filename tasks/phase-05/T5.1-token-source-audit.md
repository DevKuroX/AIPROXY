## Execution

### Step 1: Find All Token Reads

```bash
cd /home/ubuntu/ai_proxy/frontend
rg -n "localStorage.getItem\(['\"]token" src/
rg -n "localStorage\['token'\]" src/
rg -n "\.token" src/store/
```

### Step 2: Find All Token Writes

```bash
rg -n "localStorage.setItem\(['\"]token" src/
rg -n "localStorage\['token'\]\s*=" src/
```

### Step 3: Find All Token Clears

```bash
rg -n "localStorage.removeItem\(['\"]token" src/
```

### Step 4: Find Token in State

```bash
rg -n "token:" src/store/
```

### Step 5: Create Inventory

Create `docs/migration/inventory/token-sources.md`:

```markdown
# Token Source Inventory

## Token Reads

| File | Line | Pattern | Consumer |
|------|------|---------|----------|
| src/lib/api.ts | 15 | localStorage.getItem('token') | api.ts |
| src/store/userStore.ts | 10 | state.token | userStore |
| ... | ... | ... | ... |

## Token Writes

| File | Line | Pattern | When |
|------|------|---------|------|
| src/app/api/auth/callback/route.ts | 25 | localStorage.setItem('token') | OAuth callback |
| src/app/login/page.tsx | 30 | localStorage.setItem('token') | Login success |
| ... | ... | ... | ... |

## Token Clears

| File | Line | Pattern | When |
|------|------|---------|------|
| src/store/userStore.ts | 50 | localStorage.removeItem('token') | Logout |
| ... | ... | ... | ... |

## Recommendations

1. Unify token access in `src/lib/api.ts`
2. Remove token from userStore state
3. Use `authFetch` for all authenticated requests
```
