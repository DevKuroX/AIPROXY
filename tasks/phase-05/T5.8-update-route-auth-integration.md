## Execution

### Step 1: Identify Routes Using Direct Fetch

```bash
cd /home/ubuntu/ai_proxy/frontend
rg -n "fetch\(" src/app/api/
```

### Step 2: Identify Routes Using Local Token

```bash
rg -n "localStorage.getItem\(['\"]token" src/app/api/
```

### Step 3: Update Each Route

For each route that doesn't use `authFetch`:

```typescript
// Before
const token = localStorage.getItem('token');
const response = await fetch('/api/backend/endpoint', {
  headers: {
    Authorization: `Bearer ${token}`
  }
});

// After
import { authFetch } from '@/lib/http';

const response = await authFetch('/api/backend/endpoint');
```

### Step 4: Update Route Handlers

Ensure all route handlers use `proxyToBackend` which internally uses `authFetch`:

```typescript
import { proxyToBackend } from '@/lib/proxy';

export async function GET(request: Request) {
  return proxyToBackend(request, '/api/endpoint');
}
```

### Step 5: Verify Token Forwarding

```bash
# Test with curl
curl -H "Authorization: Bearer test-token" http://localhost:3000/api/providers
```

Verify token is forwarded to backend.

### Step 6: Verify Build

```bash
tsc --noEmit
npm run build
```
