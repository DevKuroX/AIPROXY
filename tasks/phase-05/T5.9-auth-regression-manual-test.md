## Test Scenarios

### 1. Login with Valid Credentials

**Steps**:
1. Navigate to `/login`
2. Enter valid email and password
3. Submit form

**Expected**:
- Redirect to dashboard
- Token stored in localStorage
- User profile loaded in userStore
- Dashboard renders with user data

---

### 2. Login with Invalid Credentials

**Steps**:
1. Navigate to `/login`
2. Enter invalid email and/or password
3. Submit form

**Expected**:
- Stay on login page
- Inline error message displayed
- No token stored
- Error message preserved (matches 9router behavior)

---

### 3. Session Persists on Reload

**Steps**:
1. Login successfully
2. Reload the page

**Expected**:
- User stays logged in
- Token still in localStorage
- Dashboard renders without re-login
- No flash of login page

---

### 4. Logout Clears State

**Steps**:
1. Login successfully
2. Click logout button

**Expected**:
- Token removed from localStorage
- userStore cleared
- Redirect to `/login`
- No orphan state

---

### 5. Expired Token Redirects

**Steps**:
1. Login successfully
2. Manually corrupt/expire token in localStorage
3. Make any API request

**Expected**:
- 401 response handled
- Redirect to `/login`
- Token cleared

---

### 6. OAuth Flow Complete

**Steps**:
1. Click "Login with [Provider]" button
2. Complete OAuth on provider site
3. Return to callback URL

**Expected**:
- Callback forwards code to backend
- Backend returns token
- Token stored
- Redirect to dashboard
- User profile loaded
