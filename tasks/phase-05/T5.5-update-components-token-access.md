## Objective

Update all components that access token directly to use `getToken()`.

## Prerequisites

- T5.2 complete (unified token retrieval)
- T5.4 complete (userStore updated)

## Execution

### Step 1: Find Components With Direct Token Access

```bash
cd /home/ubuntu/ai_proxy/frontend
rg -n "localStorage.getItem\(['\"]token" src/app/
rg -n "localStorage.getItem\(['\"]token" src/components/
rg -n "\.token" src/app/
rg -n "\.token" src/components/
```

### Step 2: Update Each Component

```typescript
// Before
const token = localStorage.getItem('token');
if (!token) {
  router.push('/login');
  return;
}

// After
import { getToken } from '@/lib/api';

const token = getToken();
if (!token) {
  router.push('/login');
  return;
}
```

### Step 3: Update Auth Guards

If there are auth guard components:

```typescript
// Before
const { token } = useUserStore();

// After
import { getToken } from '@/lib/api';

const isAuthenticated = !!getToken();
```

### Step 4: Update Protected Routes

Ensure protected routes check `getToken()`:

```typescript
// middleware.ts or layout.tsx
import { getToken } from '@/lib/api';

if (!getToken()) {
  redirect('/login');
}
```

### Step 5: Verify Build

```bash
tsc --noEmit
npm run build
```
