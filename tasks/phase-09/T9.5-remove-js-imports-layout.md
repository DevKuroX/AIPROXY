## Objective

## Execution

### Step 1: Find Explicit .js Imports

```bash
cd /home/ubuntu/ai_proxy/frontend
rg -n "from ['\"].*layout\.js" src/
rg -n "from ['\"].*page\.js" src/
rg -n "import.*layout\.js" src/
rg -n "import.*page\.js" src/
```

### Step 2: Update Imports

If any found, remove the `.js` extension:

```typescript
// Before
import { Layout } from './layout.js';

// After
import { Layout } from './layout';
```

### Step 3: Verify Build

```bash
tsc --noEmit
npm run build
```
