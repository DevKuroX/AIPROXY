## Execution

### Step 1: Install Husky

```bash
cd /home/ubuntu/ai_proxy/frontend
npm install -D husky
npx husky init
```

### Step 2: Create Pre-commit Hook

```bash
cat > .husky/pre-commit << 'EOF'
#!/usr/bin/env sh
. "$(dirname -- "$0")/_/husky.sh"

echo "Running architecture checks..."

# Check for forbidden imports
forbidden=(
  "better-sqlite3"
  "sqlite3"
  "@/lib/db"
  "@/lib/usageDb"
  "@/lib/localDb"
  "@/lib/dataDir"
  "open-sse"
)

for pattern in "${forbidden[@]}"; do
  if grep -r "$pattern" src/ --include="*.ts" --include="*.tsx" 2>/dev/null; then
    echo "❌ Forbidden import found: $pattern"
    echo "Frontend must not use: SQLite, filesystem, or provider logic"
    exit 1
  fi
done

echo "✓ Architecture checks passed"

# Run lint
npm run lint

# Run type check
tsc --noEmit
EOF

chmod +x .husky/pre-commit
```

### Step 3: Configure package.json

```json
{
  "scripts": {
    "prepare": "husky install"
  }
}
```

### Step 4: Test Hook

```bash
# Make a test commit
git add .
git commit -m "test: pre-commit hook"
```

### Step 5: Verify Hook Works

The hook should:
1. Check for forbidden imports
2. Run lint
3. Run type check

If any fail, commit should be blocked.
